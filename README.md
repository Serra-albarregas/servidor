# Programación en entorno servidor - JSP y Servlet

Este repositorio reúne material teórico y ejemplos prácticos sobre Java Servlets y JavaServer Pages (JSP), tecnologías clave para el desarrollo de aplicaciones web en Java.
Incluye explicaciones conceptuales, fragmentos de código y proyectos de ejemplo que muestran cómo manejar peticiones HTTP, gestionar sesiones, interactuar con bases de datos y generar contenido dinámico en el lado del servidor.
